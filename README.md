# Personal Mini-Toolkit (PLP Python Week 8 Final Project)

## Description
This project brings together core Python concepts—variables, loops, conditionals, and lists—into a unified, menu-driven toolkit application containing three distinct interactive utilities.

## Files
* **toolkit_plan.txt** — Initial architectural plan detailing the structure, menus, and concepts used.
* **toolkit.py** — Main executable program featuring a menu-loop structure and three tools (To-Do List, Number Guessing Game, Tip Calculator).

## How to Run
1. Ensure you have Python 3 installed.
2. Open a terminal or command prompt in the project directory.
3. Run the following command:
   ```bash
   python toolkit.py
